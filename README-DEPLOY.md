# Publish Odd One Outs on GitHub Pages

1. Extract this ZIP and upload **all of its contents** to the root of one GitHub repository. Keep the `images` folder beside `index.html`.
2. On GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**. Select the branch that contains the files (normally `main`) and choose `/(root)`, then save.
4. Wait a minute or two for the published link. Refresh the page with `Ctrl+F5` if an earlier cached version appears.

Do not upload just `index.html`, and do not put the images in a different folder. The logo and all 292 poster files must remain in `images/` exactly as supplied.
